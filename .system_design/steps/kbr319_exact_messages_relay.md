# KBR-319 — Exact Claude Code Messages relay

## Planned delivery

For an eligible subscription backend on `/v1/messages`, retain the incoming JSON bytes and end-to-end headers, forwarding them directly to Anthropic. The raw relay bypasses translation, model replacement, compaction, request mutation, synthetic authorization, and token refresh. It supports normal and SSE responses; it preserves an incoming `x-api-key` but never synthesizes one.

## Decisions and why

- **Relay raw bytes, not decoded JSON.** `request.json()` plus `json=` changes whitespace, ordering, escapes, and duplicate-key behavior, so it cannot meet the byte-preservation contract.
- **Forward end-to-end headers, with transport exceptions.** OAuth authorization and Anthropic feature/version headers are part of Claude Code's request. Authority, hop-by-hop headers, and HTTP framing are invalid across the localhost-to-Anthropic hop and must be regenerated by the HTTP client.
- **Do not expose raw relay on other ingress protocols.** Those clients cannot form a native Claude Code OAuth Messages request; translating them would violate the subscription boundary.
